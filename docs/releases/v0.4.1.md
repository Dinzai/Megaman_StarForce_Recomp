## Star Force Recomp v0.4.1

**Fixes**
- Colors: the screen output had red and blue swapped, which turned skin blue and Mega Man orange. All graphics now show their real colors.

**New**
- GitHub releases: every `v*` tag builds a signed APK and attaches it here.
- Stable signing: future builds install over this one and keep your saves.

**Upgrading from 0.4.0:** 0.4.0 was signed with a temporary key, so uninstall it once before installing this APK. Uninstalling removes the imported ROM and saves; import the ROM again afterwards. From now on, updates install over the top.

Install `StarForceRecomp-v0.4.1.apk`, then import your own *Mega Man Star Force – Leo (USA)* dump. No game data is included.

To cut a later release, commit `docs/releases/vX.Y.Z.md` to main; the Release APK workflow tags and publishes it.
