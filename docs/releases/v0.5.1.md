## Star Force Recomp v0.5.1

**New**
- **Save import converts other versions:** *Settings → Import save* accepts Action Replay `.duc` files and converts **Pegasus and Dragon** saves to Leo. The save header names the version (`rr1_p/l/d061026`) and has a simple checksum; see `docs/SAVES.md`.
- **Transformations confirmed in battle:** each form (Pegasus, Dragon, Leo, Zerker, Ninja, Saurian) appears in place of Mega Man, animates and shows its own textures, using the *Always in battle* option.

**For developers**
- `sfhost --watch LO:HI[:rw]` logs which code reads or writes memory (observation hooks).

Installs over v0.5.0.
