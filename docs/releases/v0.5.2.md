## Star Force Recomp v0.5.2

**Voxel mod in game, fixed**
- The voxel mod now covers **both screens**. Star Force 1 plays the field on the bottom screen, which v0.5.0 left flat, so the mod was barely visible there and not at all on the Thor's second display.
- The bottom screen uses an oblique 3D view whose floor stays aligned with the touch panel, so taps still land where they look. The top screen keeps the tilted camera (drag to orbit).
- New **in-game menu → Voxel mod: on/off** switches instantly, without restarting the game.
- **Settings → Voxel screens:** both / top / bottom.
- Safer startup: checks for OpenGL ES 3, tries several graphics configurations, and falls back to the normal screen with a message if the voxel renderer can't start.

Installs over v0.5.1.
