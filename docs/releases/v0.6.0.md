## Star Force Recomp v0.6.0

**Real transformations**
- *Transformations → Real Ice Pegasus / Fire Leo / Green Dragon*: Mega Man starts every battle **actually transformed**, using the game's own transformation with that form's charged shot (Flame Burner, Ice Slash, Woody Shot), element, weakness and effects (Pegasus's wings, for example). Hitting him with his weakness still knocks him out of it.
- Combine a real form with a model swap (*When transforming*) for, say, Zerker's look with Fire Leo's mechanics.
- How it works: the battle code reads Mega Man's starting form from one byte and runs its own transform routine. The mod sets that byte only while the battle code is loaded. Details in `docs/TRANSFORMATIONS.md`.

Installs over v0.5.3.
